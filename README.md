# HR-Analytics-Project
HR Analytics Project using SQL, Excel, Power BI and Tableau to analyze employee performance, attrition and workforce trends.
👥 HR Analytics Project

📌 Project Overview

This project focuses on analyzing Human Resources data to understand employee attrition, workforce trends, employee performance, and organizational insights. The analysis is performed using SQL, Excel, Power BI, and Tableau.

🛠 Tools & Technologies

- SQL
- Microsoft Excel
- Power BI
- Tableau

🎯 Project Objectives

- Analyze employee attrition trends
- Monitor workforce performance
- Identify key HR metrics
- Support data-driven HR decisions
- Create interactive dashboards

📊 Key Skills Demonstrated

- Data Cleaning
- Data Analysis
- Data Visualization
- Dashboard Development
- Business Intelligence
- HR Analytics

📂 Repository Contents

- SQL Queries
- Excel Dashboard
- Power BI Dashboard
- Tableau Dashboard
- Project Presentation (PPT)

📈 Dashboard Highlights

- Employee Attrition Analysis
- Department-wise Performance
- Workforce Demographics
- Employee Satisfaction Metrics
- HR KPI Monitoring

🚀 Business Impact

The analysis helps organizations understand employee behavior, reduce attrition, improve workforce planning, and make informed HR decisions.
